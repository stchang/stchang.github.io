1 A Context-Free Language?🔗

Here is a language whose strings resemble simple Python programs.

\mathit{PY}_{420} = \left\{\texttt{if:}\!\hookleftarrow\!\diamond^*\texttt{print}\diamond 1\hookleftarrow\texttt{el:}\!\hookleftarrow\!\diamond^*\texttt{print}\diamond 2\mid\diamond\textrm{s after "if" must match those after "else"}\right\}

\Sigma = \left\{\texttt{if:},\texttt{el:},\texttt{print},\hookleftarrow,1,2,\diamond\right\} (in real-world grammars, terminal (i.e., alphabet) "symbols" can be, and often are, whole words)

Prove: \mathit{PY}_{420} IS-A Context-free Language (CFL)

Your proof must use correct proof syntax and constructors from this semester, and must use the CFG representation of CFLs.

2 Inductive Proof Involving CFG Derivations🔗

Imagine we wish to prove the following statement for string derivations using some CFG G=\left\langle V,\Sigma,R,S\right\rangle:

IF \alpha\Rightarrow_G^*\beta THEN \gamma_1\alpha\gamma_2\Rightarrow_G^*\gamma_1\beta\gamma_2

where \alpha,\beta,\gamma_1,\gamma_2\in (V\cup\Sigma)^*

In other words, if a grammar G can derive a string, then it can derive the same string as a substring in a larger string.

  • Prove the following Lemma Statement \mathrm{HW72a}: \textrm{IF }\alpha\Rightarrow_G\beta\textrm{ THEN }\gamma_1\alpha\gamma_2\Rightarrow_G\gamma_1\beta\gamma_2 You will need to use the "Definition of \Rightarrow_G", the single-step derivation arrow, as a Justification in the proof. (Note this Lemma Statement, which uses the single-step arrow is unrelated to the main statement above, so the multi-step arrow \Rightarrow_G^* should not appear in this proof). This is a very straightforward and short proof so anything longer than a few lines is probably on the wrong track

  • Now use \mathrm{HW72a} to prove the main statement above.

    Since \Rightarrow_G^* is a recursive defintion, the proof must also be recursive, i.e., you must use proof by induction.

    Make sure your proof uses the correct proof syntax and constructors from this semester.
